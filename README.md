# 水下考古潜水记录

直接打开 `index.html` 使用（无需构建）。点击沉船平面图添加器物标记，标记保存时归入已有潜次。

## 功能

- 潜次档案：录入编号、日期、潜水员、最大深度；潜次里还有标记时，需先把标记改派到其他潜次，才能撤下原潜次
- 器物标记：保存时必须选择已有潜次；列表支持按潜次、按类型筛选
- 潜次时间线：按日期排列，展示每个潜次的最大深度与器物数量
- 导出 JSON：包含版本号、潜次与标记
- 旧版数据（仅标记数组）打开后自动迁移，所有旧标记补成一个“待整理”潜次，原潜次文本保留在备注中

## 模块划分

- `js/storage.js`：本地存储、版本迁移与初始数据
- `js/diveView.js`：地图标记、标记列表、潜次时间线与潜次档案的渲染
- `js/exporter.js`：带版本号的 JSON 导出
- `js/main.js`：页面交互与事件绑定
