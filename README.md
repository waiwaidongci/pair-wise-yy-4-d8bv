# 水下考古潜水记录

直接打开 `index.html` 使用（纯静态页面，数据保存在浏览器本地）。

- 潜次档案：录入编号、日期、潜水员和最大深度；保存标记时归到已有潜次。
- 撤下潜次时若仍有标记，需先把标记改派到其他潜次，再撤下原潜次。
- 标记列表支持按类型、按潜次筛选；时间线展示每个潜次的最大深度与器物数量。
- 导出 JSON 包含版本号、潜次与标记；旧版本地数据打开后自动迁移到“待整理”潜次。

## 模块划分

- `js/storage.js`：本地存储、版本管理与旧数据迁移
- `js/diveView.js`：标记列表、潜次时间线、潜次档案等视图渲染
- `js/exporter.js`：归档 JSON 导出
- `js/app.js`：页面交互（地图选点、表单、筛选）
- `index.html`：页面结构与样式
